3 修改程式碼預設值

📝
打開 index_simple.html
🔍
找到 getStudentId() 函數
✏️
修改最後的 'student1' 為想要的學生
function getStudentId() { const urlParams = new URLSearchParams(window.location.search); return urlParams.get('id') || 'student1'; ← 改成 'student2' 到 'student24' }
💡 推薦場景： 固定展示某位學生、個人作品集

📱 如何製作 QR Code

🌐
前往 QR Code 生成網站（如：qr.ioi.tw）
📋
複製學生的完整網址（例如：https://您的網站.com/index_simple.html?id=student1）
🖼️
生成並下載 QR Code 圖片
🖨️
列印或分享給學生使用

✨ 每位學生都可以有自己專屬的 QR Code！
