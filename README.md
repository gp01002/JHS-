## 🎮 互動功能使用方式

### 點擊3D模型：
1. 在作品展示頁面
2. 點擊3D模型任何位置
3. 會飄出該學生的專屬圖案
4. 圖案向上飄浮然後消失
5. 可以連續點擊，產生多個圖案

### 效果：
- ✨ 波紋效果：點擊處產生白色波紋
- 🎈 飄浮動畫：圖案向上飄浮
- 🎯 隨機偏移：每次飄浮方向略有不同
- ⏱️ 自動消失：1.5秒後自動移除

## 🐑 student23 雙羊模型說明

### 檔案要求：
需要上傳兩個模型檔案：
```
MODELS/23.glb     ← 第一隻羊
MODELS/23-2.glb   ← 第二隻羊
```

### 顯示效果：
- 兩個模型並排顯示
- 每個佔 48% 寬度
- 可以獨立旋轉
- 都有自動旋轉功能

### 如果只有一個模型：
如果只上傳了 23.glb，可以：
- 複製 23.glb 並改名為 23-2.glb
- 這樣會顯示兩個相同的羊
